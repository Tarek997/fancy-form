# Fancy Token Swap Form

A beautiful and intuitive token exchange interface built with React, TypeScript, and Tailwind CSS.

## Features
- Real-time exchange rate calculation
- 36+ tokens with live price data
- Token images and icons
- Input validation with error messages
- Smooth animations and transitions
- Responsive design

## Example
Swap 1 ETH → ~1645.93 USD

## Tech Stack
- React 19 + TypeScript
- Tailwind CSS v4
- Vite (build tool)
- react-select (dropdown)
- axios (API calls)

## Run
```bash
npm install
npm run dev
```
